# InfinityButtons 1.21.1

## Description
InfinityButtons 1.21.1 brings all the amazing features of the [InfinityButtons](https://github.com/TeamDiopside/InfinityButtons-1.19) mod to the newer Minecraft version 1.21.1 on NeoForge!

This project is an unofficial fork of the [TeamDiopside/InfinityButtons-1.19](https://github.com/TeamDiopside/InfinityButtons-1.19) repository, ported to NeoForge 1.21.1. It adds a huge variety of new buttons, levers and switches to the game — from plain stone and wooden buttons to large buttons, copper buttons, emergency buttons, safe emergency buttons, letter buttons, hidden "secret" buttons, torch and lantern buttons, console buttons and doorbells.

All optional dependencies and legacy version integrations have been stripped out; this port only contains the core mod content.

## Important!
This is an unofficial port and may contain bugs or slight differences from the original mod. **Back up your world** before using it. You need [NeoForge 1.21.1](https://neoforged.net/) to run this mod.

## Compatibility
This mod supports **Minecraft 1.21.1** with **NeoForge** and has **no required dependencies** besides NeoForge itself. It does not include integrations with other mods.

## Development
To help us improve this mod, you can report any problems you encounter to our [issue tracker](https://github.com/TeR1R1/InfinityButtons-1.21/issues) in this repository.

Please refrain from reporting any issues related to this port on the official [TeamDiopside/InfinityButtons-1.19](https://github.com/TeamDiopside/InfinityButtons-1.19) repository — that project is for the original mod only.

## Building from source
```
./gradlew build
```
The built jar will be in `build/libs/`.
